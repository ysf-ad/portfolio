# Yousif Aldakoki / Portfolio

Static HTML, CSS, and a small progressive-enhancement script. No install or build step.

## Preview

Open `index.html` in a browser. Assets and the resume are local and work without a server.

## Hosting

- Repository: `ysf-ad/portfolio`
- GitHub Pages publishes the root of `main`.
- Custom domain: `yousifaldakoki.com`, preserved in `CNAME`.
- Cloudflare proxies the public site. Content updates need no DNS changes.
- To publish, review changes and merge into `main`. Pages builds automatically; browser and Cloudflare caching may delay visibility.
